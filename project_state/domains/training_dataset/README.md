# Domain: training_dataset

> **Skeleton — not execution authority.** This README declares which kinds of

> authorizes execution in any round.

definitions, curation manifests, and training provenance records.

- Dataset definitions
- Curation manifests
- Training provenance records
- Dataset quality reports

## Phase A Status

future rounds can place training dataset state here without ambiguity.
