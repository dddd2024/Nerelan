# State Manifest

`project_state/state_manifest.json` is a compact index for the current project state. It records the active decision, round, report, pytest result, command plan, execution log, final check, closeout status, latest accepted baseline, generated governance artifacts, historical nonblocking artifacts, and optional missing artifacts.

The manifest does not replace source evidence. Its job is to point future planners and auditors to the right current files without scanning full history or `solve_reports/`.

Artifact roles are explicit:

- `current`: live authority or current evidence files.
- `generated_or_updated`: artifacts generated by the current governance round.
- `historical_nonblocking`: old sample or background state that should not block this governance round.
- `archived`: accepted baseline archive references.
- `missing_optional` and `missing_blocking`: missing paths classified by current-round relevance.

Historical sample artifact gaps are nonblocking for `project_governance` unless a future decision explicitly makes them current evidence.
