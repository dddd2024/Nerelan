Errors: ContextBuilderError(ValueError), stable sanitized codes; never embed raw git output, paths or database content in errors.

Packet schema: schema_version=1, authority='NONE', task (id, repository, status, execution_id, title), goal (null or id, revision, artifact_digest, objective, spec_markdown, plan_markdown), tasks (current goal linked task id/status/execution_id/title/failure_classification summaries), git (head, diff_digest, changed_paths), sources (list), history (list), omissions (dict with nonnegative counters). Sources carry kind, ref, version, digest and status. Digest is canonical SHA256 of projected source content before compaction. Status is CURRENT, UNRESOLVED or CONFLICT; unverified evidence references are UNRESOLVED. No new authority or task transitions.

Reconstruct from durable TaskStore and existing platform_goals/links and durable run observation, never a stored chat summary. Goal linkage only uses current revision; task, Goal and linked repository identity must agree or raise. If task belongs only to an old goal revision, reject as context_goal_stale. Without Goal, goal=null. Completed tasks are represented by their actual durable status; READY_FOR_REVIEW is never relabeled as accepted/completed. Preserve failed attempt classification and important event references, even when descriptions are compacted. Events expose id/type/timestamp/title/description only; NEVER raw_log or arbitrary metadata. Evidence exposes id/category/status and reference/value plus digest of original row, NEVER detail/raw JSON. Validate evidence against Task visibility; any unavailable artifact content is explicitly UNRESOLVED, never silently certified. Checkpoint uses current accepted_checkpoint/run_id/execution_id and is a source, not authority.

Visibility is trusted caller policy, not task payload: None allows current-goal tasks in same repository, explicit IDs restrict even within Goal; always include current task. Excluded IDs, their content and evidence cannot leak into sources/history/omissions (counts may be aggregate only). visible_paths is exact repository-relative POSIX paths, empty means no file content or changed filenames. Reject absolute/drive/backslash/traversal/.git paths and symbolic link/junction escapes. Do not read file content; include scoped diff metadata and digest. Git HEAD must equal a valid 40-hex expected_head; stale/missing commit fails. Bind origin to task.repository using existing normalization. Check HEAD again after observation. Git diff uses --no-ext-diff/--no-textconv; no hooks or untrusted code execution. Include staged and unstaged changes to allowed paths, and untracked allowed paths through content digests. Excluded paths never affect packet diff digest.

Bound budget integer 1024..262144 (bool rejected). Deterministic under unchanged durable/Git input; detached copies, no mutable store aliases. Prioritize identities, source references and durable status; compact long text/event descriptions deterministically with omissions counters. If required identities/references cannot fit, raise context_budget_insufficient; never truncate invalid JSON or silently omit required current-task/failure/checkpoint facts. Rebuild after store close/reopen, forced session loss and different agent yields same projection. No model calls/network/new DB/secret access. No arbitrary evidence file reads.
