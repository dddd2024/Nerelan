## 1. Upstream source findings + practical disposition

### A. Standardized low-level spans: **BORROW OPTIONAL DIAGNOSTIC PROJECTION P1**

- [`spec/README.md` L16–46](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/spec/README.md#L16-L46) uses OpenTelemetry spans, `openinference.span.kind` `LLM/AGENT/TOOL/RETRIEVER/EMBEDDING`, prompt/output/token attrs; tool call IDs and nested parent/span contexts are useful for debugging multi-Agent work. **Span ancestry / agent claims are not a Host principal or TaskStore receipt.** A span emitted from an untrusted worker could contain an arbitrary session/task label.
- [`context_attributes.py` L110–179](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/src/openinference/instrumentation/context_attributes.py#L110-L179) provides scoped `using_attributes` and `session.id/user.id/metadata/prompt template` propagation. [`_tracers.py` L143–231](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/src/openinference/instrumentation/_tracers.py#L143-L231) merges context/user attributes into start span; masking before sampler (important) then mask-aware Span setter. **Nerelan candidate**: Host-owned `goal_id/task_id/attempt_id/executor_kind/binding/request_reference/operation_id + observed_phase + source_status` in a bounded telemetry projection with opaque correlation handles. The host must map trusted IDs from its own record; do not accept a worker-supplied owner/tenant/session as authorization.
- Crucial **scope gap**: Nerelan's main actual execution path is an out-of-process OpenCode CLI via `opencode_executor.py`; attaching Python SDK instrumentation to **Nerelan Host alone** does **not** capture all CLI internal model calls, provider fallbacks, or upstream Magpie requests. Without explicit traceparent transport and Magpie verified request IDs, claim `CORRELATION_UNVERIFIED`. Do not backfill missing usage from timing-only matches.

### B. Default TraceConfig can leak prompts and giant payloads: **P0 REJECT DEFAULTS, ALLOWLIST FIRST**

- [`config.py` L82–146](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/src/openinference/instrumentation/config.py#L82-L146): `DEFAULT_HIDE_INPUTS/OUTPUTS/INPUT_MESSAGES/OUTPUT_MESSAGES/LLM_TOOLS/INVOCATION_PARAMETERS/EMBEDDING_TEXT/etc = False`. [L146–310](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/src/openinference/instrumentation/config.py#L146-L310) documents defaults favor maximum observability. This is okay for explicitly trusted demo workloads but **not okay by default** for Nerelan owner prompts, provider credentials, tool args, workspace files, internal test details.
- [`config.py` L355–455](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/src/openinference/instrumentation/config.py#L355-L455) `mask()` selectively handles semconv keys (incl `input.value`, `output.value`, `llm.input_messages`, `llm.tools`, `retrieval.documents`). It does not provide a universal scanner for arbitrary custom `metadata` / `exception.message` or unknown attribute keys. **Even `hide_inputs=True` alone does not establish all outbound fields safe**: implement a positive allowlist in Host **before serialization/export**, plus bounded lengths and sensitive string/category stripping. Reject logs/trace stored in browser raw event path per #375.
- [`_tracers.py` L155–229](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/src/openinference/instrumentation/_tracers.py#L155-L229) masks before sampler and uses a no-externalization view before the actual mask, so sampled-out/suppressed spans shouldn't upload blobs. [`_tracer_providers.py` L47–71](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/src/openinference/instrumentation/_tracer_providers.py#L47-L71) sets **10,000 attribute** default unless OTEL limits provided; this is designed for high-fidelity LLM observability, not bounded low-overhead Nerelan. Explicit small cap, event rate, TTL, local-only export, dropped-spans counter, and **no effect on TaskStore** when collector unavailable.
- [`_spans.py` L40–80](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/src/openinference/instrumentation/_spans.py#L40-L80) avoids actual external blob upload on non-recording/ended spans; no guarantee that every other app logging layer follows this contract.

### C. Streaming transparency and duplicate instrumentation: **P1 TEST_FIRST, NOT BILLING SOURCE**

- [`litellm/__init__.py` L1046–1160](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/instrumentation/openinference-instrumentation-litellm/src/openinference/instrumentation/litellm/__init__.py#L1046-L1160): `_TracedSyncStream` / `_TracedAsyncStream` wrap response streams, preserve proxy type, end span on early close/unread, propagate close/aclose to underlying provider stream; [tests/test_streaming_transparency.py L38–157, L262–314](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/instrumentation/openinference-instrumentation-litellm/tests/test_streaming_transparency.py#L38-L157) explicitly cover one span, partial output, no false error, and releasing wrapped stream (**tests read, not run**). This is a useful *model streaming/TCP lifecycle* invariant for Nerelan's stalled/partial-output observer, but no guarantee child OS processes were cleaned.
- [`litellm/__init__.py` L1055–1095](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/instrumentation/openinference-instrumentation-litellm/src/openinference/instrumentation/litellm/__init__.py#L1055-L1095), [L1510–1652](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/instrumentation/openinference-instrumentation-litellm/src/openinference/instrumentation/litellm/__init__.py#L1510-L1652) `_IN_RESPONSES_CALL` and matched `litellm_logging_obj.call_type` avoid duplicate LLM spans from `responses()→completion()` bridge, while a separately user-triggered completion during the call should remain visible. [tests/test_responses.py L384–469](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/instrumentation/openinference-instrumentation-litellm/tests/test_responses.py#L384-L469) checks exactly-one-span. **Do not conflate span count with real provider requests**: SDK retries, nested layers and external CLI requests can differ. Usage/dedup needs trustworthy Magpie request ID and per-attempt receipt, not span name/model/time.
- [`litellm/__init__.py` L1362–1405](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/instrumentation/openinference-instrumentation-litellm/src/openinference/instrumentation/litellm/__init__.py#L1362-L1405) instrumentor **monkey-patches** LiteLLM's global functions, a strong reason not to turn it on by default inside production Host. It also wraps `completion_with_retries` (L1655), with potential nesting that must be tested before aggregating usage by span count.
- [`litellm/__init__.py` L825–925](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/instrumentation/openinference-instrumentation-litellm/src/openinference/instrumentation/litellm/__init__.py#L825-L925) maps provider response usage to prompt, cache, completion/reasoning and `llm.cost.total` from LiteLLM response usage or `_hidden_params.response_cost`. When absent, attrs may not be populated; **missing is UNKNOWN, not zero**. [tests/test_token_counts.py L130–173](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/instrumentation/openinference-instrumentation-litellm/tests/test_token_counts.py#L130-L173) verifies token details are not accidentally presented as USD cost. Span cost != Magpie settled subscription consumption, especially routing fallback and native account CLIs; continue existing usage ledger [#1342](https://github.com/dddd2024/Nerelan/issues/1342).

### D. Multimodal blob uploader and plugin trust: **P0 NO DIRECT UNTRUSTED PLUGIN ADOPTION**

- [`config.py` L455–510](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/src/openinference/instrumentation/config.py#L455-L510) oversized Base64 data URI can be offloaded to configured uploader; fallback redacts when absent/bad URI. [`_blob_upload.py` L120–179](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/src/openinference/instrumentation/_blob_upload.py#L120-L179) `OPENINFERENCE_BLOB_UPLOADER` selects an `openinference_blob_uploader` Python entry point and dynamically `load()` / constructs class; this is **trusted extension code execution**, not an MCP/App authorization model. Never allow untrusted repository content or Agent output to set this env var / select uploader / supply third-party installed Python entrypoints.
- [tests/test_blob_upload.py L132–161](https://github.com/Arize-ai/openinference/blob/d2cb14105bd9f613ad4780200663c56b065443b1/python/openinference-instrumentation/tests/test_blob_upload.py#L132-L161) asserts hidden content takes precedence over upload and sampled-out spans do not call uploader; no live test executed by this study.
- In Nerelan, **disable blob externalization by default**; if later approved, use a host-owned local service/allowlisted destination, no raw path/secret media, authenticated per-scope URI, owner gate for any cross-machine upload. Even a valid `s3://` / `https://` URI is syntax, not authorized egress.

- [`opencode_executor.py` L165–230, L1359–1417](https://github.com/dddd2024/Nerelan/blob/b48cc9b82893be222e2ccdb307dd4a81bebee935/reverse_agent/platform_v1/opencode_executor.py#L165-L230) already redacts some CLI event streams and retains `_STDOUT_LINE_SINK` via ContextVar; do not trust this partial redaction as OTLP general egress safe or attempt to inject Python tracing into OpenCode CLI. - [`magpie.py` L251–287](https://github.com/dddd2024/Nerelan/blob/b48cc9b82893be222e2ccdb307dd4a81bebee935/reverse_agent/model_access/magpie.py#L251-L287) currently fetches hello, models and quotas (default off), not request-level usage; correct settled request identity still belongs to Magpie integration #1342/#1170, not an inference from `SpanAttributes.LLM_MODEL_NAME` or timestamp.
- **Product delta**: a `NerelanDiagnosticSpan` projection over existing host events with `source=HOST_CONFIRMED/CLI_SELF_REPORT/GATEWAY_CONFIRMED/INFERRED/UNKNOWN`, `phase`, `reason`, `safe action identity`, and optional untrusted OTel trace link, **no prompts or arbitrary metadata**. Useful for differentiating `WAITING_FOR_MODEL`, `LOCAL_TOOL_EXEC`, `RETRY_BACKOFF`, `UNKNOWN_STALL`. Don't let an optional tracer cause task failure or stall.

## 3. Suggested minimal provider-free tests — planned, NOT RUN

1. **Default PII leak**: default `TraceConfig` fed secret prompt/tool arguments, inputs/outputs appear in MemorySpanExport; Nerelan's export allowlist must strip all prompt/tool/response/headers/credentials regardless of upstream defaults and scrub exception metadata too.
2. **Mask vs custom attribute**: `hide_inputs=True` does not necessarily redact `metadata`, custom trace attributes or `exception.message`; verify Nerelan second allowlist, not relying on conventional keys only.
3. **Sampler / blob gate**: an `ALWAYS_OFF` span and suppressed span with large data URI perform **zero uploader calls**, hide_input_images overrides configured upload; any non-host uploader name or external URI denied.
4. **Streaming early close**: fake sync/async LiteLLM stream emits one partial chunk then closes: no false `COMPLETED`, underlying stream closed, result marked partial/UNKNOWN; no duplicate/unfinished span leaks after collector cancel.
5. **Responses bridge**: `responses()` internally calls `completion()`; count one logical LLM span for matching inner bridge; an independent nested completion still counted separately. Verify total request count independently from gateway receipt IDs.
6. **Hidden retries & cross-process**: 1 Host Agent phase, fake CLI emits zero OTel Span, Magpie records 3 requests from 2 retries; Host reports complete request count if correlated by positive IDs, otherwise usage attribution UNKNOWN; never guess through timestamps.
7. **Usage dimensions**: cached prompt tokens included in total prompt; reasoning separate from output where appropriate; absent cost attribute = UNKNOWN (not free); SDK `response_cost` is `ESTIMATED_OR_REPORTED`, not actual cash; compare to Magpie route receipt.
8. **Context forged owner**: adversarial trace metadata `session.id=other-tenant` or fake request id; Host never allows privilege/visibility via span, only verified TaskStore/gateway ids; duplicate trace export cannot bill twice.
9. **Payload budget**: 10k semconv fields or giant image/text; host enforces explicit attribute/byte/event caps, redaction before sampling, drops diagnostic spans without changing TaskStore Goal outcome; collector outage increments missing diagnostic coverage, never blocks execution.
10. **Plugin entry point abuse**: `OPENINFERENCE_BLOB_UPLOADER` set from untrusted repo/Agent instruction to executable entry point; **Host refuses before import**; no implicit cloud upload or runtime dependency.
11. **Real value gate**: production decision only after small opt-in local provider-free traces prove zero secret export, bounded CPU/RAM/disk/network, no regression in scheduler/streaming; later real tests measure accepted-goal fraction, Magpie cash, missing usage and reduced UNKNOWN root cause, not Span volume.

## 4. Recommendation & status

**P0** Host allowlist and no raw prompts / OTLP egress as default, independent request settlement, fail-closed trace identity, no untrusted blob plugins. **P1** borrow semconv kind + context/stream lifecycle for the existing run/read model, with non-authoritative correlation and explicit gaps. **P2** opt-in lightweight OTel compatible exporter only if measured provider-free utility; no Phoenix server or tracing UI duplication. **NO-GO** second billing ledger, second coordinator, automatic monkey patching of Host LiteLLM without isolation, bulk OTLP prompt export, treating all CLI requests as visible by Python tracer.

**Evidence**: inspected pinned Python SDK core, LiteLLM instrumentor, stream/bridged response/token count/BlobUploader tests (source read only), Nerelan same-baseline implementation/Issue owners, and current public OpenInference spec. Did **not** install Python dependencies, run tests, touch production host, run Magpie/provider requests, issue credential-based probes, benchmark cost/quality, run CI or independent review, merge or implement runtime. No claim of tested effectiveness or production safety.
