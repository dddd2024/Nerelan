## 1. Source findings and concrete module reuse

### A. Host-controlled outbound HTTP/TLS + DNS/protocol gates (**P0 BORROW DESIGN, NO DIRECT WINDOWS RUNTIME**)

- [`host/src/http/hooks.ts` L95–111, L197–249](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/host/src/http/hooks.ts#L95-L111): `createHttpHooks({allowedHosts,allowedInternalHosts,blockInternalRanges,isRequestAllowed,isIpAllowed,secrets})`; `allowedHosts` **omitted means `["*"]`** — public-network egress open, not deny-by-default. Explicit `allowedHosts:[]` denies all. Internal IP range blocking defaults true, but exceptions are configurable. [`host/test/http-hooks.test.ts` L798–845](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/host/test/http-hooks.test.ts#L798-L845) contains upstream examples proving these options (source read; **not executed**).
- [`native/crates/gondolin-egress/src/lib.rs` L1–12](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/native/crates/gondolin-egress/src/lib.rs#L1-L12) and [`classify.rs` L61–92](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/native/crates/gondolin-egress/src/classify.rs#L61-L92) distinguish permitted HTTP/1.x, recognized TLS ClientHello, explicit SSH and mapped TCP, and deny other raw protocols instead of offering arbitrary NAT. [`docs/security.md` L146–222](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/docs/security.md#L146-L222) documents exceptions.
- **Critical exceptions:** [`docs/network-access.md` L163–180](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/docs/network-access.md#L163-L180) `dns.mode=trusted` forwards genuine resolver queries and can still expose queried names, while `dns.mode=open` forwards arbitrary UDP/53 payloads enabling tunneling; [L217–258](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/docs/network-access.md#L217-L258) explicit mapped TCP bypasses normal HTTP parsing, per-request hooks and placeholder substitution. - **Nerelan slice:** a `HostEgressDecision` pure projection: `goal/attempt/operation + exact approved remote host/protocol/port + workspace trust + policy digest + expiry + secret scope`. Default deny for untrusted workspace code; allow only exact endpoints for validated tasks; no `dns.open`, broad SSH, raw TCP, local metadata or arbitrary host-to-guest ingress by default. Test first under #299/#447/#303; no need to copy the TS/Rust proxy itself.

### B. Secret placeholders substituted by trusted host (**P0 BORROW CONCEPT, NEVER EXPOSE HOST CREDENTIALS**)

- [`host/src/http/hooks.ts` L197–341, L416–439](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/host/src/http/hooks.ts#L197-L341): `createHttpHooks` constructs per-secret random placeholder env values; real values remain on host; secret manager can rotate/revoke and update allowed hosts; late substitution is restricted to secret's host allowlist. [`native/crates/gondolin-egress/src/secrets.rs` L31–68, L73–121](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/native/crates/gondolin-egress/src/secrets.rs#L31-L121) mirrors header and URL query replacement and checks revoked/actual secrets for allowed destination. [`docs/secrets.md` L14–40](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/docs/secrets.md#L14-L40) explicitly states **secret host-scoping does NOT restrict network egress**; must combine with `allowedHosts`. [`host/test/http-hooks.test.ts` L686–847](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/host/test/http-hooks.test.ts#L686-L847) covers rotation, deletion, revoked strings, public egress default and deny-all. Read, not run.
- Placeholder substitution by default applies primarily to **headers** (including Basic auth) and *optionally* query params; it is not a generic rule for arbitrary opaque message bodies. And [`docs/security.md` L237–263](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/docs/security.md#L237-L263) acknowledges a destination server may echo secrets back, negating the higher-level secrecy goal. If the daemon or Host is compromised, it holds real secrets. [`docs/security.md` L62–70](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/docs/security.md#L62-L70) notes daemon receives secrets, private MITM CA and host mount access.
- **Nerelan slice:** host-only credential broker for previously authorized provider endpoints, guest/executor sees opaque capability reference or placeholder, exact `destination + account/role + task/attempt + operation + policy_version` gates before each request; deny if end-to-end proxying cannot be controlled; never send raw provider/Magpie tokens into untrusted Agent process, tools, Worktree, history, logs, Browser UI. Secrets, real provider calls and system configuration are **R3**, not authorized by this document.

### C. Guest filesystem as explicit mounted capabilities (**P1 BORROW PATTERN**)

- [`host/src/vfs/mounts.ts` L20–57, L66–87, L270–289](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/host/src/vfs/mounts.ts#L20-L87) `MountRouterProvider` dispatches by longest matching mount and rejects cross-mount rename/link; [`host/test/vfs-mounts.test.ts` L35–52, L102–114, L145–211](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/host/test/vfs-mounts.test.ts#L145-L211) verifies mount path normalization, invalid/duplicate paths, cross-mount write/link restrictions, normalization of `..` traversal and nested mount precedence (read only). [`docs/security.md` L263–303](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/docs/security.md#L263-L303) documents provider chain and defense against escaping host mounts via symlinks.
- **Nerelan slice:** explicit narrow approved worktree, read-only reference mounts, scratch writable dirs, no mount of host root, Magpie credentials, SSH keys or other repo worktrees. Link/rename/copy/realpath and Windows junction/reparse-point checks must be tested separately; upstream POSIX VM behavior **does not verify Windows symlink semantics**. Capture approved `base_sha/allowed_paths/artifact_digest/mount_policy_digest` in TaskStore state and do not let untrusted Agent update authority by modifying a repo config file.
- Owner #299/#303; `capability_registry.py` is a metadata catalog, not a Host-authorized VFS broker or plugin runtime.

### D. Checkpoint != durable Agent execution, and reload changes policy context (**P0 FAIL-CLOSED RECOVERY TESTS; P1 BORROW ARTIFACT IDENTITY**)

- [`docs/snapshots.md` L115–180, L337–353](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/docs/snapshots.md#L115-L180): `vm.checkpoint(path)` stops/consumes VM and records **qcow2 root disk only**. Process state, memory, tmpfs (`/root`, `/tmp`, etc.) and external VFS mounts **not checkpointed**; `sync` is best effort. [`host/src/checkpoint.ts` L346–500](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/host/src/checkpoint.ts#L346-L500): in-process object resumes with merge of remembered VM options, but `VmCheckpoint.load(file)` creates a checkpoint **without base options**; explicit config must be supplied again. Backend compatibility and image build ID checked; code does **not** prove Owner approval of old mounts/egress/credentials.
- [`docs/snapshots.md` L150–161, L325–353](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/docs/snapshots.md#L150-L161) documents atomic replacement of checkpoint output but also warns resuming can **mutate the checkpoint header in place** for backing path rebase; no immutable snapshot evidence should be assumed. [`host/test/checkpoint.test.ts` L34–132, L146–259, L370–390](https://github.com/earendil-works/gondolin/blob/ca98da589edd0cd1c79333c0a2229660bb43d37b/host/test/checkpoint.test.ts#L34-L132) checks qcow2 resumption isolation, build compatibility and backend mismatch (source read only).
- **Nerelan slice:** treat snapshot as **mutable workspace artifact with declared root-disk digest, image/build digest, base Git SHA, mount/network policy digests, captured/uncaptured paths, exec scope and content-provenance status**. On restart: create a new fenced executor lease, reapprove current workspace and network policies, reconcile pending external operations *before dispatch*, and start a **new process**, not reuse old call/result success state. If provenance or pending remote side effect is unknown, block automatic replay.
- Preserve existing [TaskStore](https://github.com/dddd2024/Nerelan/blob/0ddd4ef5e1a9d472c93b1563c8c0250b85068e8b/reverse_agent/platform_v1/run_store.py) (lease epochs/receipts) and [GoalService](https://github.com/dddd2024/Nerelan/blob/0ddd4ef5e1a9d472c93b1563c8c0250b85068e8b/reverse_agent/platform_v1/goal_service.py) external-operation hold; no second snapshot state engine.

## 2. Minimal provider-free test ideas (PLANNED, not executed)

1. **Egress absent allowlist:** `allowedHosts` omitted upstream yields wildcard; Nerelan default for untrusted job DENY, including external public hosts; explicit exact allowed hostname/protocol/port passes only approved intent.
2. **Internal and DNS:** block localhost, metadata IP, RFC1918, DNS rebound IPv4/v6; `dns.mode=open` (UDP53 tunnel) and permissive `trusted` DNS reject without explicit policy; no `tcp.hosts` generic bypass.
3. **HTTP protocol drift:** verify HTTP/1.1-only proxy and unsupported HTTP2/3/WebSocket opaque-upgrade do not silently bypass later tool egress expectations.
4. **Secret placeholder:** Guest observes marker not real token; only approved exact provider receives substituted header; disabled/rotated/deleted secret refuses, disallowed redirect/host fails.
5. **Secret reflection:** approved target reflects inserted token in response body: response egress/log/snapshot pipeline must not treat placeholder scheme as complete secret-non-disclosure; redact or deny reflection.
6. **Body/query/opaque tunnels:** secret replacement only supported headers + optional URL query; don't assume arbitrary body or raw TCP/SSH substitutions or per-request scan.
7. **VFS escape:** `..`, symlink/junction, absolute path, cross-mount rename/link, nested mount masking, concurrent worktrees, host path race; deny access outside approved root; don't infer Windows safety from POSIX tests.
8. **Snapshot disk-only:** write to root disk and tmpfs and mounted worktree, snapshot, reboot; only root-disk expected; old running PID/opaque process marker must be INVALID. No old action considered settled just because filesystem exists.
9. **Snapshot policy drift:** loaded qcow2 image holds outdated manifest or policy; refuse restore without fresh `policy_digest/base_sha/allowed_paths/workspace`; no previous credential/network approval inherited from in-memory object.
10. **Checkpoint integrity / mutate:** atomic replacement leaves old checkpoint on failure; subsequent resume that mutates header cannot be used as immutable accepted artifact without re-hash/copy. Reconcile run claims/epochs.
11. **Ambiguous external operation:** Agent invokes remote tool then VM crashes before receipt; exactly one pending external operation remains, **do not auto replay on a new VM**.
12. **Resource ceiling and economics:** limit VM startup timeout, CPU/RAM/disk, no full DoS guarantee; failed boot/snapshot/cleanup does not strand Goal; count VM/roundtrip overhead and Magpie all-attempt usage in accepted-change-per-cost comparison.
13. **Host compatibility:** on supported macOS/Linux only *if separately authorized*; Windows native must report UNSUPPORTED instead of installing private binaries or unsafe fallback; no WSL2 assertion without separate tested plan.
14. **Policy authority:** repository-supplied VM/mount/network configuration cannot expand Host grant; provenance and access trace must tie to current goal/task/attempt lease, not agent output or plugin manifest.
