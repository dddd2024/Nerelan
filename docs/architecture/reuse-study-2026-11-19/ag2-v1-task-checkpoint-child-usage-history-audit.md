## 1. Detailed pinned source findings

### A. Task progress, checkpoint and accepted completion are three separate truths (**P0 BORROW_GUARD + REJECT DIRECT SEMANTICS**)

- [`ag2/task.py` L93–112](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/task.py#L93-L112): `CheckpointStore` protocol offers `write/read(task_id, opaque_json)`; task author chooses exactly what to persist and interprets it on resume, framework does not validate side effects. [L316–336](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/task.py#L316-L336): `Task.progress(payload)` merges into in-memory `metadata.progress` and emits `TaskProgress` — **not a snapshot or evidence a task's real action succeeded**.
- [L437–454](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/task.py#L437-L454): `Task.checkpoint` is a **silent no-op** with no checkpoint store; [L484–494](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/task.py#L484-L494) `resume_from` reads a prior checkpoint and sets opaque `resumed_state` to dict or None. [`test/network/test_task_durability.py` L116–185](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/test/network/test_task_durability.py#L116-L185) tests no-store no-op, missing prior checkpoint → None, terminal checkpoints ignored; tests **read only, not run**.
- [`ag2/network/hub/core.py` L1985–2009](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/network/hub/core.py#L1985-L2009) persists **single JSON blob, last-write-wins, no history** per task; does not include lease epoch, command effect evidence, snapshot hash or independent acceptance. [`test/network/test_task_durability.py` L216–254](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/test/network/test_task_durability.py#L216-L254) validates overwrite/resume roundtrip, not arbitrated exactly-once remote effects.
- [`ag2/task.py` L528–558](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/task.py#L528-L558) context manager clean exit auto-transitions to `COMPLETED`; [`test/test_task.py` L90–111](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/test/test_task.py#L90-L111) proves a task that merely exits cleanly emits `TaskCompleted`. **No independent software artifact evaluator there.**
- **Nerelan mapping:** preserve [`run_store.py`](https://github.com/dddd2024/Nerelan/blob/974686eea3709d04c8383a28e76bdb4748053205/reverse_agent/platform_v1/run_store.py) durable claim epoch + External Operation receipt, [`goal_service.py` L300–405](https://github.com/dddd2024/Nerelan/blob/974686eea3709d04c8383a28e76bdb4748053205/reverse_agent/platform_v1/goal_service.py#L300-L405) unknown operation hold, [`cost_quality_benchmark.py` L58–141](https://github.com/dddd2024/Nerelan/blob/974686eea3709d04c8383a28e76bdb4748053205/reverse_agent/platform_v1/cost_quality_benchmark.py#L58-L141) acceptance only by independent trusted evaluator. Potential `TaskCheckpointEvidence` is a **fenced snapshot of proposed continuation hints**, not a new state DB; never mark accepted from AG2 `COMPLETED`, progress output or last-write-wins checkpoint. Missing checkpoint on an attempt requiring durable restart should be `CHECKPOINT_MISSING/UNKNOWN`, not no-op.

### B. Interrupted tool-call transcript repair is useful, but synthetic results are not host tool receipts (**P0 BORROW PURE TRANSFORM #1696/#1556**)

- [`ag2/history.py` L172–224](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/history.py#L172-L224) recognizes tool calls in both `ModelResponse.tool_calls` and `ToolCallsEvent` and dedupes by tool-call id, including process death **between response persistence and emitted tool-call event**. [L226–282](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/history.py#L226-L282) inserts synthetic `ToolResultEvent` for unreturned calls, rebuilds full `ToolResultsEvent` wrapper for incomplete batches, and does `History.replace` rather than publish a new action-triggering event.
- [`test/tools/test_final_tool_history.py` L20–67, L128–155](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/test/tools/test_final_tool_history.py#L20-L67) tests complete batches remain unchanged after speculative repair; read, not run. [`test/test_compact.py` L88–135](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/test/test_compact.py#L88-L135) tests not splitting paired tool calls across compaction.
- **Important non-equivalence:** `synthetic ToolResult("interrupted")` = conversation-format repair only; tool may already have succeeded on GitHub/FS/Remote Agent then lost ACK. Such a synthetic result must **NOT** be passed into Nerelan TaskStore as actual command result, nor trigger auto re-execution. Bind original `attempt_id/tool_call_id/external_operation_id` to Host receipt; if unresolved, hold `UNKNOWN` and perhaps let model read safe diagnostic after reconciliation. Also don't count `ToolResultsEvent` as independently accepted feature.

### C. Sub-agent accounting: one source record counted once, not cumulative rollups (**P0 BORROW PURE ACCOUNTING RULE #1342/#1267**)

- [`ag2/tools/subagents/run_task.py` L60–110](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/tools/subagents/run_task.py#L60-L110) child delegation emits original usage as events immediately; `TaskResult.usage` is **cumulative snapshot for inspection only**. [`_forwarding.py` L270–324](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/tools/subagents/_forwarding.py#L270-L324) forwards without re-publishing a new usage event ID, preserves origin event identity; on delivery exception, attempts to persist accounting so failed forwarding does not erase spend.
- [`docs/adr/0032-account-descendant-usage-from-source-events.md` L15–53](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/docs/adr/0032-account-descendant-usage-from-source-events.md#L15-L53) removes parent rollup generation, source original `UsageEvent` once per publication; two different real calls with identical counters are **two different spend records**. [`docs/adr/0014-token-accounting-reads-usageevent.md` L19–92](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/docs/adr/0014-token-accounting-reads-usageevent.md#L19-L92) shows why summing child cost + cumulative parent snapshot double bills; compaction and maintenance calls need their own source.
- **Remote gap (explicit upstream warning):** [ADR 0014 L143–148](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/docs/adr/0014-token-accounting-reads-usageevent.md#L143-L148) `TaskMirror` forwards lifecycle metadata, **not complete remote usage history**. In-process source event accounting success **does NOT demonstrate cross-machine/CLI/Magpie usage completeness**.
- **Nerelan mapping:** use exact trusted gateway request IDs or TaskStore UsageObservation IDs, not amount/model/time heuristic; preserve `source/status=OBSERVED/UNKNOWN`; full model retries, compaction, subagents, fallback are admitted cost. [`usage_ledger.py` L226–320](https://github.com/dddd2024/Nerelan/blob/974686eea3709d04c8383a28e76bdb4748053205/reverse_agent/platform_v1/usage_ledger.py#L226-L320) already treats list price vs cash invoice and UNKNOWN distinctly. No new spending ledger. Even AG2 UsageEvent is a model/framework report, not real subscription invoice.

### D. Compaction keeps tool boundaries and source usage, but archival and summarization costs differ (**P1 BORROW TESTS #context**)

- [`ag2/compact.py` L73–130](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/compact.py#L73-L130) counts conversational events separately from interleaved usage telemetry; `TailWindowCompact` calls `snap(events, cut)` so it does **not cut a tool-call/result pair**. If `KnowledgeStore` is supplied, dropped events are archived via `EventLogWriter` first; no knowledge store → old content is deleted from active history without persistent archive. [`test/test_compact.py` L88–136, L170–210](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/test/test_compact.py#L88-L136) exercises tool cycle and usage retention.
- [`compact.py` L133–205](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/compact.py#L133-L205) `SummarizeCompact` separately calls LLM, emits `UsageEvent(kind="compaction")` to real agent stream; so summaries are **not free** and missing account/Magpie reports still UNKNOWN. [`test/test_compact.py` L230–351](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/test/test_compact.py#L230-L351) tests accounting survives compaction, no duplicate source records.
- **Nerelan mapping:** current [`context_recovery.py` L72–84, L123–199](https://github.com/dddd2024/Nerelan/blob/974686eea3709d04c8383a28e76bdb4748053205/reverse_agent/platform_v1/context_recovery.py#L72-L199) already has digest-bound ContextHandoff/ContextSummary, snapshot matching, and central TaskStore source. **No competing memory database or history rewrite**. Borrow only pure provider-free test matrix: tool/result pair cannot be split, original source evidence preserved before compaction, cost record stays outside LLM prompt, summary does not gain authority to replace code/command receipts.

### E. Network identity and resume are scoped, but Hub self-reported capability is not quality (**P1 BORROW POLICY, NO SECOND HUB**)

- [`ag2/network/hub/core.py` L264–336, L2792–2876](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/network/hub/core.py#L264-L336) classifies wire ops **before dispatch** into unscoped discovery, connection-bound agent identity, channel participants and task ownership; unknown operations rejected. [L2943–2960](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/network/hub/core.py#L2943-L2960) first checkpoint writer for unobserved task owns subsequent checkpoint access under a hub-local lock. [`test/network/test_connection_identity.py` L260–302](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/test/network/test_connection_identity.py#L260-L302) checks another authenticated connection cannot rewrite first writer's checkpoint (read only).
- **Sharp edge:** [`ag2/network/rule.py` L58–88](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/network/rule.py#L58-L88) `ChannelTypeAccess` and `AccessBlock` default to `["*"]` inbound/outbound and initiation; `RateBlock(per_minute=0)` disables limiter by default, and comment notes rate stored but **not enforced by in-process Hub**. This is not sufficient as Nerelan Host-level Account/Tool permission. [`identity.py` L144–161](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/network/identity.py#L144-L161) `claimed_capabilities` are tenant claims; `observed` derives from terminal Task events and [`hub/core.py` L1500–1557](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/network/hub/core.py#L1500-L1557) records `COMPLETED`, not independent functional acceptance.
- **Nerelan mapping:** reuse wire-bound identity/participant isolation tests, no cross-task checkpoint access and no Task ID path traversal. Remote Agent discovery/capability claims may influence candidate ranking but **never** authorize tools, change Owner grant or prove a feature is accepted. Existing #1508 multi-agent orchestrator and TaskStore should remain the authority; no AG2 Hub deployment justified.

### F. Approval "always" + Skill subprocess are NOT secure defaults (**P0 REJECT TRUST BOUNDARY**)

- [`ag2/middleware/builtin/tools/approval.py` L14–80](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/middleware/builtin/tools/approval.py#L14-L80) `approval_required` accepts `always` into `context.variables[BYPASS_KEY]` keyed to `event.source` or fallback `event.name`; [`test/middleware/builtins/test_approval.py` L114–145, L172–284](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/test/middleware/builtins/test_approval.py#L114-L145) confirms repeated same implementation skipped and different same-name tools prompt independently. However a missing source fallback is name-based and the grant is a **session variable**, with no proof of claim epoch, argument digest, budget, revocation, expiry or Owner-backed receipt. Timeout defaults `None`: legitimate human wait can hang indefinitely without Host-level pending-approval status and cancellation policy.
- [`ag2/tools/skills/runtime/local/runtime.py` L34–55, L142–178, L216–240](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/tools/skills/runtime/local/runtime.py#L34-L55) `LocalRuntime` defaults to local subprocess, optional sandbox; `blocked` command prefix list explicitly says **not a security boundary** (e.g. shell wrappers bypass it). This is **not a sandbox for untrusted repo-supplied skills**, despite path normalization. [`run_task.py` L37–59](https://github.com/ag2ai/ag2/blob/6d2dd8bab8af873ea29ed759cfacb572466d925e/ag2/tools/subagents/run_task.py#L37-L59) inherits parent dependencies into worker unless overridden, making unfiltered Host service objects and secrets a concrete integration risk.
- **Nerelan mapping:** #253 Pack manifests are **metadata only** [`capability_registry.py` L1–121](https://github.com/dddd2024/Nerelan/blob/974686eea3709d04c8383a28e76bdb4748053205/reverse_agent/platform_v1/capability_registry.py#L1-L121); #299 sandbox, #303 repo trust, #790 MCP and #447 egress own code execution/credential authority. No trust via `allow_always` context variable or filename/blacklist. Call-time Host grant must be scope-bound (`tenant/goal/attempt/operation/tool-schema/arguments_digest/claim_epoch/expiry`) and rechecked after resume. Subagents inherit only explicitly delegated, immutable non-sensitive context, never parent TaskStore/credential handles. All tool effects require existing receipt.

## 2. Proposed provider-free failure fixtures — PLANNED, NOT RUN

1. **A1 No checkpoint store:** `checkpoint()` silent upstream; Nerelan required-durable step fails closed as `MISSING_CHECKPOINT`, cannot claim successful persisted recovery.
2. **A2 Stale overwrite:** two attempts write same task checkpoint with different epochs; later stale write must reject, not last-write-wins; resumed state must match owner/Goal/base SHA/claim and policy.
3. **A3 Unknown resume:** checkpoint `None`, missing schema or mismatched base: do not hallucinate partial state; keep external effects unresolved and choose safe restart or hold.
4. **A4 Clean exit vs accepted:** task context exits cleanly and auto COMPLETED without artifact; independent evaluator must reject claimed delivery and cost per accepted Goal denominator counts it as nonaccepted.
5. **A5 Crash between ModelResponse and ToolCallsEvent:** repair finds call in response despite absent wrapper, uses synthetic interrupted result; cannot replay real tool without Host effect receipt.
6. **A6 Multi-call batch partially complete:** restore complete prior results and synthetic unknowns as transcript repair only; no new tool invocation event or duplicate previously finished external effect.
7. **A7 Source usage identity:** parent and child both observe same `event_id` → charge once; two requests same amount but different verified IDs → charge twice; rolled-up snapshot never added.
8. **A8 Remote child gap:** TaskMirror reports child COMPLETED but no source request receipts; child spend attribution UNKNOWN, not $0; no false accepted artifact.
9. **A9 Compaction boundary:** never split tool-call/result cycle, preserve source usage after multiple summaries, archive original before replacing; no ability to rewrite immutable receipts with a summary.
10. **A10 Summary overhead:** summary LLM call generates distinct usage and every attempt is accounted with Magpie, possibly UNKNOWN; compare no-compaction vs tail window vs summarization acceptance & spend.
11. **A11 Wire ownership:** forged agent ID, task path traversal, wrong channel participant, second writer's checkpoint, stale reconnect and tool alias refused; no claim-based permission escalation.
12. **A12 Claimed vs observed capability:** self-reported capability and terminal `COMPLETED` without independent verifier have 0 accepted samples; ranking cannot treat them as proven quality.
13. **A13 Approval revocation:** session `always` stored, then Owner revokes permission / schema or request arguments change; next action must be denied despite in-memory bypass flag; no indefinite approval wait misread as model stall.
14. **A14 Local Skill escape:** untrusted `script` wraps blocked cmd in child shell, runs from default local subprocess; Nerelan gate blocks execution prior to loading, requires approved sandbox + command receipt.
15. **A15 Context inheritance:** parent dependencies include Python DB/secret/Magpie client; child agent must receive none absent explicit narrow approved delegation, including remote worker and cross-tenant.
16. **A16 Cancellation:** child TaskCancelled event / text stop does not imply OS child killed, provider call cancelled or effect rolled back; rely on actual executor stop receipt + unresolved-operation hold.
17. **A17 Looping progress:** repeated TaskProgress events without accepted artefact do not reset cumulative interruption/work budget forever; exercise in #1696 chaos bed.
18. **A18 Value gate:** provider-free same frozen feature inputs single vs multi-model: account for all planner/worker/subagent/summary/retry costs, accepted artifact via independent checker and rate of UNKNOWN receipts. Do not optimize raw completion-event count.

## 3. Recommendation & evidence state

**P0** immediate source-inspired pure tests: (i) checkpoint vs progress/terminal truth; (ii) interrupted-tool transcript repair separate from external operation effects; (iii) dedup child source usage; (iv) no Host approval from context variables, channel wildcard or local skill blacklist. Add to **existing #1696 chaos bed, #1556 diagnostics, #1342 usage, #1267 acceptance, #1508 multiagent, #303/#299 security**, not a new runtime or repeated implementation ticket.

**P1** borrow context compaction tool/result boundary and archive-before-summary, first-writer checkpoint read rules, origin event tracing, scoped child dependencies and wire participant authorization, but retain existing ContextRecoveryService + TaskStore. **REJECT DIRECT** AG2 Network Hub/Store as a second coordinator, Agent Context `COMPLETED` as acceptance, AG2 `RateBlock` as enforced account budget, wildcard channel discovery as plugin authority, local skills as safe subprocess, and snapshot usage as settled invoice.
