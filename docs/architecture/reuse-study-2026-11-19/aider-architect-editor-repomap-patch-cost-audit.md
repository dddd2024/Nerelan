### C. Search/Replace diagnostic and **wrong-target fallback** (**P0 REJECT BROAD FALLBACK; P1 BORROW FEEDBACK**)

- [`aider/coders/editblock_coder.py` L15–123](https://github.com/Aider-AI/aider/blob/5dc9490bb35f9729ef2c95d00a19ccd30c26339c/aider/coders/editblock_coder.py#L15-L123) parses `SEARCH/REPLACE` blocks, tries original target; when nonempty original doesn't match, it iterates **other in-chat absolute file paths** and, if a match exists, *changes edit path* to that file. Therefore an imprecise patch intended for file A could change B if same original snippet appears. This fallback is an intended interactive convenience, **NOT safe mutation authority for unattended Nerelan**. May parse shell blocks too, but shell execution has a separate prompt path; no claim this runs without approval by default.
- [`editblock_coder.py` L127–336, L364–388](https://github.com/Aider-AI/aider/blob/5dc9490bb35f9729ef2c95d00a19ccd30c26339c/aider/coders/editblock_coder.py#L127-L388) supports perfect/whitespace/fuzzy/replacement candidates; compares snippets and reports nearby lines for failed blocks. Fuzzy matching is practical for conversational coding but dangerous without exact file+base+content identity on concurrent branches. Partial successfully applied edits are described in feedback; do not silently reapply them.
- [`base_coder.py` L2296–2345](https://github.com/Aider-AI/aider/blob/5dc9490bb35f9729ef2c95d00a19ccd30c26339c/aider/coders/base_coder.py#L2296-L2345) dry-run/prepare/apply and sets `reflected_message` for parse/update failure; [L921–943](https://github.com/Aider-AI/aider/blob/5dc9490bb35f9729ef2c95d00a19ccd30c26339c/aider/coders/base_coder.py#L921-L943) caps reflection attempts at `max_reflections` 3.
- **Nerelan P0:** exact `target_path + base_tree_sha + expected_before_sha + patch_digest + allowed_paths + claim_epoch` checked before Host mutation. A request for A **must not search B** even if code matches. Duplicate snippets in target require explicit location/ambiguity failure; partial apply triggers durable receipt with per-file status, not all-or-nothing claim. Reflect a small sanitized mismatch to model, but **no auto fallback mutation** without new Host-approved action. Existing [`task_runtime.py` L188–260](https://github.com/dddd2024/Nerelan/blob/34971d979cb7dcfff58c48b3b7d0b0bc67fe9cff/reverse_agent/platform_v1/task_runtime.py#L188-L260) already requires approved bounded commands; [`run_store.py` L1430–1496](https://github.com/dddd2024/Nerelan/blob/34971d979cb7dcfff58c48b3b7d0b0bc67fe9cff/reverse_agent/platform_v1/run_store.py#L1430-L1496) binds fenced evidence. ## 2. 16 proposed provider-free acceptance/negative fixtures (NOT RUN)

1. **C1 Small Goal split overhead:** same frozen trivial function fix: strong single model vs strong plan+cheap edit; measure invocation count, transfer tokens, failure rate, total time; no assumed benefit if split costs more.
2. **C2 Hard Goal routing threshold:** same frozen multi-file change, four arms including cheap single + escalate. Compare independent ACCEPT and spent/UNKNOWN, not planner fluency.
3. **C3 Architect→Editor evidence:** plan produced, editor rejects missing target/wrong base/unsupported edit format; never accept "plan completed" as Goal completion or double-count planner/editor cost.
4. **C4 RepoMap symbol relevance:** deterministic Python package with references: ranking must favor target dependency under fixed allowed context size vs baseline file retrieval; all candidate files from approved scope.
5. **C5 mtime cache collision:** change bytes with restored original mtime; Aider cache may serve stale tags; Nerelan must invalidate by content/git-tree digest and never use stale map for edit authority.
6. **C6 Ignore/exclusion:** secret or disallowed file includes highly connected symbol; rank must never show forbidden bytes even if PageRank high.
7. **C7 Same-snippet wrong file:** patch says A but SEARCH absent in A, same snippet in B; Aider-style fallback could edit B; Nerelan must return `TARGET_MISMATCH` without mutation.
8. **C8 Ambiguous fuzzy patch:** same lines twice within A, or fuzzy nearest not exact; refuse to mutate until exact path/range/before hash is explicit; sanitised feedback only.
9. **C9 Partial apply:** block 1 succeeds, block 2 fails; persist per-block state and source SHA, retry only B2, never double-apply B1 or mark entire edit success.
10. **C10 Dirty user tree:** user-uncommitted change in B; AI edits A; commit only approved A and preserve B byte-identically, with provenance and reviewer diff.
11. **C11 Lint ≠ quality:** syntax clean but behavior wrong; `lint_success=True` yet independent functional checker REJECT; no acceptance bump.
12. **C12 Unapproved shell/test:** suggested `powershell` or custom lint/test cmd uses shell metacharacters; reject via Host-approved argv, no `shell=True` even if CLI interactive path would prompt.
13. **C13 Repair loop cap:** three malformed patches / recurring lint errors; bounded retries/cost, final `BLOCKED/FAILED` with honest evidence, not infinite attempts resetting after small progress.
14. **C14 Hidden model spend:** failed pre-stream request, LiteLLM retry, prompt cache warm, commit-message LLM and editor model; if any settlement missing, full accepted Goal cash cost remains UNKNOWN, never zero.
15. **C15 Worktree drift:** after planning, base Git Tree or allowed file set changes; editor must refuse and re-plan/reconcile, no writes against stale file list.
16. **C16 Reproducible harness matrix:** record model IDs, execution modes, full effective prompt/plan digest, RepoMap version/budget, edit format, attempts, stopping policy, workspace base, test/evaluator SHA and all account costs; avoid cached cross-arm contamination. Same accepted-artifact quality gate and denominator including all admitted tasks.
