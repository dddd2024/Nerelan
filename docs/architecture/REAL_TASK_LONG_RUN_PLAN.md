## 1. 额度约束：Claude 和 Codex 的周额度不能提前用完

Owner 的唯一预算要求。周额度配速已由 #1399 实现并合入：对 Owner 指定的订阅账户，若
`已用比例 + 本任务预计用量 > min(1 − reserve, 本周已过时间比例 + slack)`，排除该候选，理由记为
`weekly_pace`，写入既有 MODEL_SELECTED 证据，并在账户页显示。

| 配置（`model_routing_overrides.json`，Owner 可改） | 默认 |
|---|---|
| `weekly_pace.enabled` | true |
| `weekly_pace.executors` | `["codex", "claude_code"]` |
| `weekly_pace.slack` | 0.10，即允许比时间进度超前 10 个百分点 |
| `weekly_pace.reserve` | 0.10，任何时候都保留至少 10% 不用 |

当前额度（2026-11-08 06:25）：

| 账户 | 快照 | 7 天窗口已用 | 本周已过 | 重置时间 | 配速结论 |
|---|---|---|---|---|---|
| Codex | FRESH | 75% | 59% | 11-11 02:41 | 被配速挡住；即使本任务用量按 0 计，也要到约 11-08 15:54 才重新可用 |
| Claude | STALE，约 18 小时未刷新 | 81%（缓存值） | 89% | 11-09 01:00 | 无法判断，见下 |

### 快照过期时配速不生效

`weekly_pace_hold` 对未知用量或重置时间不作判断，交给既有额度规则；Magpie 的 STALE 账户
`windows` 为空，所以 Claude 快照过期期间配速不约束它。为保证"全程不越过配速线"可验证，本次长跑约定：
**Claude 快照不是 FRESH 时不使用 Claude**，包括评审备选。若评审因此缺少不同模型家族，该任务停在
Draft PR，等快照恢复或人工评审。

### 提前重置

| 情况 | 行为 | 依据 |
|---|---|---|
| 重置实际发生后 | Magpie 约每分钟刷新，观测到新窗口后配速按新的一周重算 | Magpie 额度窗口，不依赖公告 |
| Codex 已验证的重置公告，重置前 | 取决于 #1400：合入则用到只剩 `reset_buffer`（3%）；不合入则照常配速 | #1400；`model_router` 既有 drain 逻辑（#1248、#1281） |
| 公告未验证、过期、被撤回或来源不可用 | 视为没有公告，照常配速 | `reset_decision` 对 UNKNOWN/STALE 保持中立 |
| Claude 公告 | 不放开，只在观测到新窗口后放开 | `docs/claude-reset-signals.md` |

Codex 重置卡由 Owner 手动使用，Magpie 的自动使用保持关闭（Owner 决定，2026-11-07）。

## 5. 关机恢复

宿主按现有 `dev-up.ps1` 启动，开启 `REVERSE_AGENT_MULTI_ACCOUNT_ENABLED`、`REVERSE_AGENT_MAGPIE` 和反馈路由。
运行期间 Owner 主动关机一次，步骤：

1. 确认有任务正在执行（任务页显示 running，且已有租约）。
2. 正常关机。
3. 开机、登录，**手动打开 Magpie**，再启动宿主。
4. 检查任务是否从租约恢复，有没有重复执行或丢失已提交的工作。

宿主开机自启需要另装一个启动项，确认后再加。

## 6. 验收标准

| 维度 | 标准 |
|---|---|
| 额度约束 | Codex 全程不越过配速线，所有排除都有 `weekly_pace` 证据；Claude 只在快照 FRESH 时被使用，使用时不越过配速线 |
| 连续执行 | 无人干预下首轮三个任务都到 Draft PR，或给出可解释的阻塞 |
| 容错 | 记录每一次真实失败的类型，以及后续是重试、切换还是降级；没有真实失败时如实写明，不声称容错 |
| 关机恢复 | 关机前未完成的任务恢复后继续；没有同一任务的重复执行，没有丢失已提交的工作 |
| 成本与性能 | 按账户统计 Token、成功率和每个成功任务的耗时；免费和订阅账户分列 |
| 反馈优化 | 只记录策略版本变化和触发它的样本数；10 个任务以内样本不足以比较成功率或成本，不作改善结论 |
| 可回滚 | 结束后用 CLI 回滚一次策略，确认路由回到基线 |

## 7. 停止条件

任一条件满足即停止派发新任务，已在执行的任务跑完：

- Claude 或 Codex 越过配速线（不应发生，发生即视为 #1399 有缺陷）
- 连续 3 个任务失败
- 窗口 Token 上限耗尽
- 任何任务触及 R2 或 R3 路径（`AGENTS.md`、`docs/agents/**`、`.github/workflows/**`、`landing_review.py`、依赖、密钥）
- Owner 停止窗口
