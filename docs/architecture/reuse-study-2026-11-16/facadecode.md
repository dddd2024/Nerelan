### 用户价值 vs 开发成本

- **用户**：在同一桌面/网页中可以判断“我关闭界面后 Agent 是否真在跑？它是否沿用我的账号订阅？实际有没有越权的 YOLO？消息是否已提交到目标 Agent？为什么不能恢复？”这比克隆 VS Code UI 更有价值。
- **开发**：先用只读多执行器 Cap Matrix 和 provider-free reset/retry fixture 验证；不安装 VS Code fork、Node ptyd/Rust daemon，不引入新的 TaskStore、Gateway、权限系统。若原生 CLI 不支持可靠 status/receipt，保持 UNKNOWN、不要从终端屏幕猜测可计费请求或验收成功。
- **成本效益**：Facade 的本地 CLI session pooling 无 Magpie per-request settlement；不能声称借鉴终端进程即可节约 Token。任何经济性结论需独立跑同样任务，合计 Manager/Coder/Reviewer/recovery、排除重复尝试与合规回退的费用。

## 3. 七组最低限度实验（全部未执行）

1. **D1 / 默认 YOLO 权限回归（P0 #1527/#303）：** Codex/Claude/OpenCode 的自动准备中无授权将 yolo 变 true、注入其危险 flags，且显示 `sandbox effective`。同一模型/Agent 的非法 setup 必须被 Host **拒绝**，不是 warning 继续。
2. **D2 / 断线与长跑（P0 #1530/#1596）：** UI/SSH/control socket 连续断线 30s、90s、5min、10min；工作任务仍在执行/恢复/UNKNOWN，必须不因 UI grace 阈值被无故 kill；合法 Stop 另行验证，旧 epoch 迟到动作不能执行。
3. **D3 / 重复 Start 与期限越界（P0 #1508）：** `(creator,requestId)` 在 0s、3599s、3601s 重试，接受前后断电、worktree 创建前/后、进程 spawn 前/后、响应丢失；同一个已提交外部 effect 在任何时间不得另起，未知状态需 readback/PARK，不能照搬上游一小时 TTL。
4. **D4 / 不明输入效果（P1 #790）：** 消息已粘贴/CLI 还未显示/Enter 已发但屏幕未更新/输入框已有人工草稿/前台提问/读屏过时；不得重复写或越权按 Enter；UI 显示 `text_written/enter_written` 的明确状态，而不能把 “accepted/queued” 当模型读取或完成。
5. **D5 / 跨 Agent 越权（P0 #1508/#790）：** 兄弟树、另一个仓库、旧 Agent、未知 owner、同名 Agent/别名；`start/stop/read_screen/type_text/press_keys` 按 Host 真实 scope、epoch、审批独立拒绝；不可通过 YOLO 或同名解析扩大权限。
6. **D6 / Adapter 真正支持度（P1 #1527）：** OpenCode 1.x/2.x、Codex、Claude 的版本、Model/Effort selection、session identity、Sandbox/Approval 状态、Started/Waiting/Finished signal、usage source。标记不支持而不是 silent fallback；验证 Nerelan 原有安全 flags 始终有效。
7. **D7 / 定量产品收益（P1/P2 #1527/#280）：** 同一被独立验收的 Goal，baseline 现有 ExecutorRouter vs 增加 executor evidence/capabilities；观察完成率、错误重试率、UI 中“跑着但实际上终止”的误判、重复 Side-effect 率、用户操作次数、耗时和**Magpie 提供商级真实全成本**。若没有改善，保持只读观察不扩展后端。

### Go/No-Go

- **NO-GO** 若 D1 放宽 Host 沙箱/审批，D2 UI 关闭导致 Goal 被取消，D3 一个旧请求第二次运行产生外部副作用，D5 agent 跨 owner 输入键盘或审批，D6 编造 unsupported 能力，或 D7 用估计成本代替 Magpie。
- 先在 Windows provider-free fixture 测 Cap Matrix/receipt/ownership，无授权不得安装/打开用户 VS Code profile 或真实长期任务。D7 后才能考虑实验性远程执行后端。

## 4. 最终复用裁定 / 来源证明

- **ALREADY_REUSED：** Nerelan ExecutorRouter、多原生 CLI adapter（OpenCode/Codex/Claude）、TaskStore Goal/Task claims/epoch、授权收据、运行列表、Magpie 成本计量、CI+独立审查。
- **BORROW_PATTERN：** 每 CLI `Capabilities + SandboxFact + ApprovalFact`；session-generation fenced reconnect；接受前持久请求收据（但必须扩展不受 TTL 剪裁的安全 effect ledger）；`paste→draft evidence→Enter` 和 `unknown`；有歧义 run ID 拒绝；“UI disconnected != executor stopped != task verified” 三态。
- **REJECT：** YOLO 默认和跨树键盘控制；编辑器不在线超时自动终止持续 Goal；仅 1h dedup 认定全局 exactly-once；PTY socket 请求缓存代替数据库 claim/receipt；自动运行用户配置的可执行 Hooks/MCP/Plugin；把 terminal spinner 当模型完成；引入 VS Code fork 或第二运行架构。
- **DIRECT_REUSE：** **不批准**。MIT 的核心/extension 可以按许可进一步评估，但其 IDE/PTY 依赖、Windows 终端兼容、安全模型、许可证分层和真实收益尚未通过测试。此轮只用 source 行为证据，不复制运行代码。
