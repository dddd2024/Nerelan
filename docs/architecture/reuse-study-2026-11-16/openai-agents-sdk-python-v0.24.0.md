## 2. Provider-free falsification experiments (proposals, not executed)

1. **Approval collision:** Two agents share tool name and different payloads/Owner scopes; approve one call, restart and replay the other: second must stay blocked. Modify args after approval and ensure stale digest is rejected. Owner: #790/#253/#299.
2. **Mixed batch crash / repeated pause:** A safe read tool succeeds, a write tool waits for approval, crash between side effect and completion receipt; restart N times; host must not blindly re-execute the write or lose the read's evidence. A missing external effect receipt means `UNKNOWN/RECONCILE`, **not** `SUCCESS`. Owner: #1546 / current TaskStore.
3. **Failover replay safety:** Simulate first refusal (429/reset timestamp), silent executor, streamed partially emitted output, and unknown external effect; route should hold correct account scope without trying unsafe replay or spending ordinary model retries. Owner #1530/#1531.
4. **MCP admission matrix:** `require_approval=None`, unlisted tool in name mapping, server disappeared, tool list changed, hosted-vs-local MCP path; host always applies same authorization and fails required capability closed. Owner #790/#447.
5. **Trace privacy:** Capture all egress with fake transport; assert no OpenAI trace upload and no plaintext tool args/secrets; local trace must keep request/attempt identity and UNKNOWN usage. Owner #179/#1342.
6. **Context pairing:** Handoff history transformation, compaction and rejected approval must not orphan tool-call/output or leak supposedly filtered context into nested history. Owner #296.
7. **Economic gate:** Fixed tasks across existing executors and models, count setup/classification/retries/cached usage and independent acceptance. Adopt an SDK adapter only if accepted-results-per-cost beats current best baseline with bounded regression; owner #1267/#1527.

## 3. Priority and decision

- **P0 negative fixtures / avoid regression:** `approval scope collision`, unsafe replay, fail-closed MCP/defaults, local-only tracing. These are candidates for existing owners, **no new implementation Issue**.
- **P1 evidence improvements:** durable pending-output semantics, nested handoff provenance, cross-adapter trace correlation. Only if missing after exact-head code/tests review.
- **P2 optional executor adapter experiment:** No direct SDK dependency until the (harness, model) economic bake-off #1527/#1267 demonstrates benefit.
- **No-go:** installing the SDK, swapping LangGraph/TaskStore, using SDK Session as task truth, using parallel guardrails as security, enabling default external trace export, or accepting SDK per-tool approval defaults.
