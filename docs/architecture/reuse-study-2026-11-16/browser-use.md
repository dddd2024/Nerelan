## 1. What upstream actually runs (pinned 1.0 architecture)

[`README.md`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/README.md), [`agent/loop.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/agent/loop.py), [`repl/session.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/repl/session.py), [`repl/worker.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/repl/worker.py), [`agent/prompt.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/agent/prompt.py).

The upstream 1.0 rewrite is a **Pydantic AI agent which emits arbitrary Python cells into a persistent child-process REPL** with `browser-harness` utilities and raw Chrome DevTools Protocol (`cdp`), JavaScript evaluation, `subprocess`, local file access, screenshot, upload and download helpers. A narrow `Tools` custom-action wrapper [`tools.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/tools.py) is not a closed tool-only execution boundary; the model can still run Python/CDP directly. It can outlive one cell and keep Python variables; worker timeout loses Python variables but browser/files/remote effects survive.

**P0 REJECT_DIRECT_HOST_EXECUTION**: Never bind this REPL to trusted Nerelan host, user's regular Chrome profile or credential store merely because the model is authorized to browse. Its code runs as the user's OS identity if not isolated. MIT license does not imply safe integration. Structured APIs / Playwright semantic DOM / accessibility remain #802's default; evaluate this as a *separate R2 dependency/R3 execution-gated backend* only in isolated, ephemeral, low-trust, bounded container/VM with no host secrets and explicit network capability. A generic process, tmp directory, separate Chrome profile and environment allowlist are not an OS sandbox.

## 2. Source-evidence mapping by module

### A. Browser navigation guard — useful testing patterns, explicitly **not** an egress policy

[`domains.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/domains.py) `DomainRules`, `Guard`, `sweep`; [tests](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_domains.py); [README security FAQ](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/README.md).

- `allowed_domains` / `prohibited_domains` / `block_ip_addresses` normalize schemes, domains, IDN, path, user-info and ports. DomainRules rejects most disallowed main-frame URL navigation, `Guard` listens to CDP Fetch for **Document** requests, and after each Python cell `sweep` resets disallowed tabs to `about:blank`.
- **Important explicit limitations:** upstream says this is a guard for an aligned model **not a sandbox**: fetch/images/iframes/subresources, Python's own network sockets beyond the specific `http_get` helper and its redirects are not filtered. In attached `Browser('chrome')`, Guard's second CDP connection is intentionally not used, leaving weaker after-cell observation. `DomainRules` permits `data:` and `blob:` even if a domain allowlist is specified; when no rules are given restrictions are absent. IP-literal restriction must be enabled.
- **P0 BORROW_TESTS, REJECT_AUTHORITY**: canonical URL/hostname comparison and cross-tab/scheme/redirect tests are reusable *ideas*; admission for real browser actions/network must use Nerelan host-owned `BrowserTarget + full-origin scope + network/OS egress control`, not browser-use prompt/DOM guard. Negative fixture: allowed page requests disallowed host via fetch/iframe and model-written Python `urllib`; both must fail via network isolation regardless of CDP guard.

### B. Authenticated browser/profile — don't attach silently to user's real login

[`browser/local.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/browser/local.py), [`browser/browser.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/browser/browser.py), [local tests](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_local_browser.py).
- Separate fresh `Browser('chromium')` vs user's attached `Browser('chrome')` vs copied Chrome profile vs Browser Use Cloud. Profile copies carry cookies/session material; local.py explicitly mentions Chrome's platform-dependent cookie-key handling and locked cookie files. `require_debug_port` detects leftover DevTools port files and **refuses guessing local ports 9222/9223**, preventing an accidental attach to the wrong process (upstream test exists). Local browser startup/stop and fresh-profile lifecycle have dedicated tests.
- **P0 BORROW_PATTERN**: explicit target/profile identity, no CDP auto-discovery of arbitrary listening ports, positive local approval and dedicated per-task browser identity. No user's actual signed-in profile or persistent session without separately approved capability, session owner binding, private content controls and preflight. Need not copy profile with live credentials to support unrelated browsing.

### C. REPL worker cancellation/recovery: useful *cleanup*, not durable completion

[`repl/session.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/repl/session.py), [`repl/worker.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/repl/worker.py), [`browser/local.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/browser/local.py), [tests](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_repl.py) and [tests](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_loop.py).
- Parent/worker loopback connection authenticates with random 32-byte token; worker environment allowlists basic OS variables, excludes obvious credential names. Python launched with `-P` to avoid workspace import shadowing. Windows worker process is placed in a **Job Object with kill-on-close** when available; POSIX has a process group; on REPL timeout/cancel it kills/restarts worker and descendants. A browser watchdog uses parent lifecycle and PID identity to clean leaked browser/daemon on death.
- `checkpoint(..., partial=True)` writes partial results to workspace with output redaction. Model-conversation compaction and **pre-existing browser/files persist after a worker restart**, not one exactly-once business transaction. [Compaction tests](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_compaction.py) check keeping user messages and tool pairs while compacting.
- **P1 BORROW_PATTERN**: strongly bound worker generation, kill descendants on timeout, keep artifact receipts separate from execution, mark `BROWSER_SIDE_EFFECT_STATE_AMBIGUOUS` when the worker died after submission. Do not resume by replaying a submit/purchase/send/delete click. Existing Nerelan [`task_runtime.py`](https://github.com/dddd2024/Nerelan/blob/57637b338b896f00f966c60a5c67f3e0e9848c4e/reverse_agent/platform_v1/task_runtime.py) has executor-neutral result, [`task_execution.py`](https://github.com/dddd2024/Nerelan/blob/57637b338b896f00f966c60a5c67f3e0e9848c4e/reverse_agent/platform_v1/task_execution.py) owns one durable TaskStore path, and [`context_recovery.py`](https://github.com/dddd2024/Nerelan/blob/57637b338b896f00f966c60a5c67f3e0e9848c4e/reverse_agent/platform_v1/context_recovery.py) produces authority-free summaries/handoffs. **Keep these.**

### D. Sensitive inputs, uploads/downloads — existing masking is not confinement

[`repl/session.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/repl/session.py) module doc explicitly: secret values are copied into the worker; redaction hides them from selected result/checkpoint paths, **but model-written Python can read the values and host files, write unredacted files and screenshot or JS can reveal values.** [README](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/README.md) repeats this. [`remote_upload.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/remote_upload.py) accepts local file path, reads the bytes, and for cloud/remote can upload them in page-JS chunks. [`agent/service.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/agent/service.py) explicitly says the old available-file-paths allowlist is not present and arbitrary files may be read/uploaded as OS user. [`test_repl.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_repl.py) shows redaction controls and domain-scoped type_secret tests—but those do **not** give host isolation.
- **P0 NO-GO** for high-trust user sessions, host credential injection, arbitrary file upload, full CDP, external network from Python on unisolated host. For any backend, pre-authorize per artifact and target URL (upload), sandbox download directory and MIME/content/size/digest checks before using artifacts; never assert "sensitive_data hides the password from the Python process." Windows Credential Manager / model relay on trusted host must never be mounted or exposed.

### E. Cloud/provider cost and judge are not Nerelan acceptance

[`browser/browser.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/browser/browser.py) uses cloud by default if no local browser option; [`agent/service.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/agent/service.py) validates model/search availability before creating billable Cloud browser. `run(max_steps, timeout)` also excludes initial browser startup and shutdown/download-copy from its `timeout` budget. `judge` makes **another model request** to classify the run and folds model-judge costs into result usage; judge failure leaves its judgement absent rather than failing the main task. [`agent/judge.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/agent/judge.py), [judge tests](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_judge.py). [`agent/loop.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/browser_use/agent/loop.py) manages model failures and screenshot pruning with explicit prompt-cache tradeoff.
- **P1 BORROW_PATTERN** preflight before billable browser allocation, lifecycle measurements covering create/stop/idle, model judge as secondary advisory signal, screenshot minimization / cache-aware compaction. **NO-GO** if cloud costs, vendor key or extra model-judge request are silently unaccounted by Magpie/Nerelan. A judge saying success does not prove the remote site recorded intended change; require read-after-write postcondition or explicit `UNKNOWN` and human verification. Compare *total quality-adjusted cost per accepted task*, not only model tokens.

### F. Upstream tests have value, not necessarily equivalent OS/platform coverage

[domain tests](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_domains.py) include URL userinfo spoof, IDN, path segment escapes, IPv6, pseudo URL, tab sweeps and real Chrome integration; [`test_repl.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_repl.py) includes leaked child processes after cancellation, redacted partial files, command environment credential filtering; [`test_local_browser.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_local_browser.py) includes false CDP target, Windows cookie-locked profile, stale PID/watcher; [`test_compaction.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_compaction.py) preserves tool pairs; [`test_judge.py`](https://github.com/browser-use/browser-use/blob/4b5b1b0aa0ab45a1d6a2a31984d37d3e748c0134/tests/ci/test_judge.py) charges judge tokens. These are **upstream fixtures read statically**; no tests ran in this Nerelan study. Browser-use 1.0 migration changes matter: do not import older `Controller`/0.x security assumptions as if current; typed Tools in 1.0 do not forbid arbitrary Python.

## 4. Provider-free falsifiable experiments — **NOT RUN**

**E1 Security isolation (P0):** fake local site allowed-origin + injected page text asking model to use `open('/home/...')` or `urllib` to local/private IP and POST to off-domain. In actual Nerelan-bound prototype all such filesystem/network attempts must be blocked by sandbox/broker; if using plain Browser Use host process, expect policy mismatch / NO-GO. Simulate arbitrary Python `subprocess` and prevent shell/credentials on host.
**E2 Origin/scheme (P0):** test main frame redirects/new tabs vs iframe/fetch/image; data/blob/file/chrome, IPv4/IPv6, userinfo IDN, default-allow no-policy. The final host/network decision must not equal Browser Use `DomainRules` alone.
**E3 Browser identity (P0):** stale port file + fake listener on 9222/9223, attached Chrome profile collision, wrong tab, profile copied with session cookies, locked Windows cookies; require exact browser/daemon/tab binding and safe refusal, never switch to another user profile.
**E4 Side effects and restore (P0):** fake invoice/email form accepts once then hangs before response; kill worker/browser, restart using checkpoint. Verify remote state before deciding anything; never submit again automatically, store `UNKNOWN` and receipt. Stop/timeout must kill OS descendant process trees, including Windows Job Object scenario.
**E5 Upload/download/privacy (P0):** file chosen from unapproved host folder, malicious page asks to upload or screenshot secret, network redirect, oversized downloads, fake PDFs/scripts, symlinks and pre-existing download names. No off-scope bytes leave; bounded quarantine with digest/provenance; no secret in model trace, PR or logs.
**E6 Economics/quality (P1):** controlled read-only fixture web tasks; compare official Playwright SDK/MCP semantic adapter against Browser Use 1.0 isolated REPL on same model via approved Magpie connection, fixed acceptance and startup/teardown. Count model calls, judged extra token cost, cloud browser lease charges, screenshot tokens/cache misses, operator attention and completed-verified-task total cost. Any host policy violation or uncontrolled cloud billing: NO-GO.
**E7 Non-browser/backend failover (P1):** task requires structured API/MCP vs browser. Confirm API-first decision avoids browser/model cost when equivalent and that Browser Use failure does not silently fall back to OS Computer Use #785 or unbounded CDP.

## 5. Final verdict

**`P0 SECURITY_NO_GO_FOR_UNSANDBOXED_RUN / P1 SELECTIVE_BORROW_PATTERN / P2 CONDITIONAL_ISOLATED_BROWSER_BACKEND`.** Most relevant Nerelan additions are *browser target preflight, process/child lifecycle, CDP wrong-target prevention, provider-free origin test matrix, and honest cost attribution*. The most consequential negative source fact is the **arbitrary Python REPL bypassing any tool-only authorization model**; output redaction and main-frame domain guard do not meet Nerelan's host boundary.

The main product goal remains resource pooling plus quality-adjusted cost and multi-harness interoperability. This is a new modality *only if* cost, user value, postcondition quality and security can be proven. **Static source code inspected; no package installed, browser opened, cloud lease, API call, provider request, test run, CI or independent review.** Research artifact requires R1 docs Draft PR and one #1576 hub addendum, not a second #802 implementation Issue.
