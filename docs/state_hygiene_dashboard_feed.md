# State Hygiene Dashboard Feed

State Hygiene Dashboard Feed is a static JSON feed for future UI or Web display. It includes current decision, current round, latest report, final-check status, backlog notices, workstream state, cleanup readiness, compaction readiness, index readiness, archive index summary, lifecycle guard status, and forbidden capability status.

This feed does not start a Web server, define an API, create frontend code, open a database, or dispatch background work.

Primary outputs:

- `project_state/gates/state_hygiene_dashboard_feed.json`
- `project_state/gates/state_hygiene_dashboard_summary.json`
