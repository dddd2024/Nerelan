# Nerelan F1.1 Visual Template

Status: **LOCKED VISUAL TEMPLATE**

This document freezes the approved Nerelan F1.1 visual board as the canonical visual template for subsequent brand-design iterations.

![Nerelan F1.1 visual template](./assets/nerelan-f1.1-visual-template.jpg)

## Locked reference

- Design: **Nerelan Brand Design Draft F1.1 — Unified Expressive Wordmark**
- Role: visual template / mother reference for future iterations
- This is **not automatically the final production logo** and does not replace separately retained formal candidate directions unless explicitly promoted later.
- F1.2 is **not** the continuation baseline. It is treated as a rejected visual regression relative to F1.1.

## Elements that must be preserved by default

Future refinements that claim to derive from F1.1 must preserve these characteristics unless a later explicit design decision overrides them:

1. The complete `Nerelan` wordmark must read as one unified mark rather than `N + erelan`.
2. The custom `N` keeps the lighter Anchor → Link → Anchor construction and the refined inset connection.
3. The lowercase system keeps the F1.1 overall weight, width rhythm, curve character, and spacing relationship.
4. The `l` remains the quiet central spine and the wordmark retains the `Nere | lan` visual rhythm.
5. The single-storey `a` retains the low, wide bowl, open top, and short rising tail as its base silhouette.
6. The standalone `N` symbol retains the internal modular construction shown in F1.1; it must not collapse into a generic sans-serif `N`.
7. The app icon remains derived from the same symbol DNA, with the warm off-white presentation and restrained rounded-square treatment shown in the board.
8. Overall tone: expressive custom typography with controlled tension and flow; avoid both generic font output and over-engineered/cyber/AI-logo styling.

## Change-control rule

When producing the next visual iteration from this direction, use this F1.1 board as the **only visual mother template**. Do not regenerate the `N`, symbol, overall proportions, or type system from scratch merely to introduce a local refinement. Changes should be explicit, bounded, and visually attributable.

In particular, local experiments on `e` or `a` must not simplify or replace the existing `N`/symbol structure.
