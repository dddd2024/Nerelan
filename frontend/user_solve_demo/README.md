# User Solve Local Demo

This static demo previews the fixture-only User Solve frontend contract.

Open `index.html` directly or serve this directory with any static file server.
The page reads `fixtures/catalog.json` when available and falls back to embedded
fixture payloads when opened from disk.

The demo is not a production service. It does not upload files, process binaries,
persist sessions, dispatch runners, call a network API, or validate real samples.
